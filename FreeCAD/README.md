# R4875G1 Triple Rectifier Mount – FreeCAD

This directory contains the FreeCAD design for the mechanical mounting system of three Huawei R4875G1 rectifier modules used by the 3-phase charger project.

## Current Status

> **Work in Progress**

The design is still at an early stage.

The current model contains three main mounting parts:

* **Front holder**
* **Middle holder**
* **Back holder**

Together, these parts position and support three R4875G1 rectifiers mounted side by side.

The following parts are **not yet included** and are planned for future revisions:

* rear connection / wiring compartment
* mounting for cooling fans
* additional cable routing and mechanical details
* final mounting and enclosure details

Dimensions and geometry may therefore still change.

## Inspiration and Dimensions

The design was inspired by the excellent Huawei R48xx mechanical models from Patrick:

https://github.com/patagonaa/huawei-r48xx

In particular, this project uses the R48xx dimensions and mechanical geometry published there as an important reference for the rectifier fit and mounting concept.
